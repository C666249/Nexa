[PASS] Requested UI / behavior review
- To-Do ↔ Note V1.9 View Transition/fade/scale motion removed from the mode-switch path.
- New mode gesture is pure translate3d drawer-style finger follow; under threshold springs back; over ~30% or fast fling commits.
- Daily is a separate ~2/3-height rounded floating drawer, not a third main mode and not counted in Todo stats.
- Daily rows show checkbox + title + time + calendar; left swipe reveals only two separate Edit/Delete buttons.
- Daily calendar renders ✓ / × / ● in a dedicated row directly BELOW each date number; future/pre-creation dates are blank; monthly completed/eligible/percent is shown.
- Daily editor defaults new items to the current local hour/minute and defines recurrence as every day.
- Daily Banner is one line: checkbox + title + "Daily · HH:mm" + X.
- Daily Banner checkbox marks today complete and dismisses; X dismisses/ignores today without marking complete; body tap dismisses and opens/highlights the Daily row.
- If Daily is already completed today, its scheduled reminder is skipped. If ignored today, it is not repeated that day and is re-armed for the next day.
- Existing standard Todo three-state reminder Banner behavior was not changed.
