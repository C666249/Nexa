Stable
- applicationId: com.nexa.app
- app name: Nexa

Key fixes
- Todo/Daily reminder notifications and floating banners now carry an explicit target route and item id.
- MainActivity keeps reminder targets until the WebView acknowledges them, with bounded retry during startup/resume.
- Reminder entry has priority over the last-opened Nexa route and flashes the exact Todo/Daily row after navigation.
- Space/global search now marks matching text with the same one-pass gradient sweep language used by Todo search.
- Opening a global Todo/Note result carries the query into the destination so the matched content remains visibly highlighted.

No persistent storage schema was changed in this release.
