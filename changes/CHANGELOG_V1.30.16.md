# V1.30.16

## Note 搜索高亮质感优化
- 将正文搜索高亮从纯色块升级为与搜索结果卡片相同方向的青绿—淡紫渐变高亮，视觉更轻、更细腻。
- 正文关键词高亮与全文搜索命中高亮统一为圆角渐变样式，并加入一次性的柔和扫光/脉冲动画，避免上一版纯色黄块质感偏重。
- 保留原有“打开全文搜索结果后自动定位并高亮正文关键词”的行为，仅优化高亮质感与动画，不改变搜索结果逻辑。
