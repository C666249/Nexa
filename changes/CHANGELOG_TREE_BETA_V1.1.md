# Tree Beta V1.1 Changelog

- Added physical left-swipe Action Rail to Note cards in Recent and Topic Workspace.
- Physics deliberately matches Golden To-Do: 124px / 48px / 200ms ease-out.
- Initial actions: Move to Topic + Delete.
- Delete reuses existing confirmation; swipe never directly deletes.
- Move reuses Schema V2 `moveNoteToTopic()` and adds no storage key.
- Single-open rail, vertical-scroll arbitration and post-swipe click suppression.
- Card gestures no longer compete with the Note right-swipe Drawer gesture.
- Knowledge Tree/Drawer rows intentionally remain navigation-only.
- No Note Editor, IME, native, ToDo, Daily, Reminder, Banner or Snooze core changes.
