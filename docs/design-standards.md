# Nexa design standard

Reference: user's four Dashboard/Todo/Note/Daily screenshot boards, September 5, 2026.
Warm, quiet paper; no neon/glass backdrop, decorative emoji or saturated gradients.
Background #F7F2E8; cards #FFFDF8; text #2C2925; secondary #9B8265; completed #76B69B.
Secondary palette is not automatically safe for small text: verify contrast and darken
functional labels where needed. Use system CJK fonts for offline coverage and stable IME.

Bottom navigation five equal targets, >=48dp tap areas and safe-area/IME-aware placement.
Spacious hierarchy; subtle borders and shadows, natural reduced-motion-aware transitions.
Reading-first Note surface; compact tools only in editing, rich-text state unchanged.
Real empty states, not fabricated dashboard data. Screen widths 320/360/390/430dp and
large system fonts must be reviewed for overlap and clipping.

Phase1 icon: adaptive vector N, deep brown field, cream pillars and muted diagonal
ribbon. Keep mark within Android adaptive safe area; no check, alarm or folder shape.
Screen redesign is deliberately not part of Phase1 and remains pending.
