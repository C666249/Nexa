# 2026-08-11 — V1.7
- Base: V1.6 Full；用户授权完整重构此前失败的提醒子系统，To-Do/Note 其它成熟区域继续锁定。
- 复盘 V1.6 真机现象：10 秒测试在桌面不触发、重新进入 APP 后立即出现；单条待办提醒没有到点悬浮。
- 对照用户提供的 FlowLedger v1.8.1：其 OverlayBanner 直接使用 applicationContext + WindowManager + TYPE_APPLICATION_OVERLAY，并由已存活的系统绑定 Service 触发。List-Note 不引入无关 Accessibility/NotificationListener 权限，而是建立自己的低打扰前台 Reminder Keeper，复用“已有存活宿主直接挂 overlay”的生命周期特征。
- AlarmManager 升级为用户明确设定时间优先 setAlarmClock；同时保留 Receiver + 高优先通知兜底、前台 Keeper 内 Handler 二次时钟、WAKE_LOCK。
- 条目提醒由 WebView 在确认/取消时显式调用 Native Bridge，不再只依赖全量 snapshot 的隐式同步。
- 悬浮窗挂载参数按 FlowLedger 的稳定实现收敛：application WindowManager、TYPE_APPLICATION_OVERLAY、FLAG_LAYOUT_IN_SCREEN、安全状态栏/挖孔 inset。
- 左滑 UI 继续保持透明动作区 + 绿色提醒按钮 + 红色删除按钮两个独立按键；Note 模式未修改。
