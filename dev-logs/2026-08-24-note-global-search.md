# Note 全局标题搜索

- Note 模式复用顶部搜索栏，最近修改与知识树两种视图都可全局检索。
- 检索范围严格限定为笔记标题与主题（文件夹）标题，不扫描正文或附件。
- 结果展示类型与完整主题路径，命中词带安全高亮和轻量流光入场动画。
- 根据真机截图反馈，将命中文字从下半段荧光笔样式改为完整包裹字高的青紫柔和色块；流光保持不变。
- 点击笔记结果进入对应阅读页；点击主题结果进入对应主题工作区，落点有短暂聚焦动画。
- To-Do 原搜索逻辑与历史记录保持不变；Note 搜索不写入 To-Do 搜索历史。
- 新增 `tests/note-global-search.test.js`，覆盖跨类型标题命中、正文排除、HTML 转义、高亮和导航契约。
- 修复 Android 系统返回键：全局标题搜索生效时，返回键只清空筛选并留在 Note，且保持“最近修改/知识树”当前视图；不会直接切回 To-Do，也不会重新唤起键盘。
- 新增 `tests/note-global-search-back.test.js`，分别覆盖最近修改与知识树两种返回路径。

## 验证

- 浏览器实测最近修改 / 知识树结果一致，笔记 / 文件夹跳转和落点动画正常，控制台无错误或警告。
- `ui/todo.html` 与 Android assets 中的 `todo.html` SHA-256 一致。
- `:app:assembleDebug --offline --no-daemon` 构建成功。
