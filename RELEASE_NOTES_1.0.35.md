# Nexa 1.0.35 — Cross-day Todo Drag

- Long-press Todo drag is no longer limited to one date group.
- Dragging through a date divider moves the live placeholder into that date; dropping updates the task date persistently.
- Holding a dragged task near the visible top or bottom edge continuously auto-scrolls with distance-based acceleration.
- When today has no existing Todo section, reaching the top exposes a temporary “今天” drop target so overdue work can still be moved to today.
- Same-day custom ordering remains stable; source and destination day order maps are updated independently.
- Existing task status, checklist, category and reminder data are preserved.
